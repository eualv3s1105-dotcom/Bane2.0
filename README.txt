PROTOCOLO BANE — PACOTE COMPLETO INICIAL

Conteúdo:
- index.html: aplicativo com Início, Treinos, Aplicações, Alimentação e Histórico.
- assets/bane-wallpaper.jpeg: wallpaper enviado pelo usuário.
- assets/bane-icon.jpeg: imagem enviada para o ícone.
- manifest.json: configuração básica de instalação web.

PUBLICAÇÃO:
Envie todos os arquivos e a pasta assets para a raiz do projeto na Vercel ou GitHub Pages. Mantenha o nome index.html.

Os registros ficam no armazenamento local do navegador deste dispositivo. Use Exportar meus dados para guardar um backup.
No iPhone, abra o endereço publicado no Safari e use Compartilhar > Adicionar à Tela de Início.
